# CampusGPT - Next-Gen AI Campus Portal

CampusGPT is a full-stack, AI-powered university portal and assistant designed for students, faculty, and administrators. It features a modern dark-mode user interface with custom signature color gradients, interactive role-based authentication, an asynchronous Python FastAPI backend, and MongoDB database integration.

---

## 🌟 Tech Stack

### Frontend (`/client`)
- **Framework**: Next.js 16 (App Router with Server Actions)
- **UI & Styling**: Tailwind CSS, Shadcn UI, Lucide Icons
- **HTTP Client**: Centralized `apiClient` with cookie-based JWT session management
- **Language**: TypeScript

### Backend (`/server`)
- **Framework**: Python FastAPI
- **Database**: MongoDB (Async via Motor)
- **Security**: Password hashing & PyJWT token creation
- **Server**: Uvicorn ASGI Server
- **Language**: Python 3.10+

### 2. Start the Backend Server (FastAPI)

1. Open a terminal and navigate to the `server` folder:
   ```bash
   cd server
   ```

2. Create a virtual environment (optional but recommended):
   ```bash
   # Windows
   python -m venv venv
   .\venv\Scripts\activate

   # macOS / Linux
   python3 -m venv venv
   source venv/bin/activate
   ```
   
3. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Launch the FastAPI server:
   ```bash
   python run.py
   ```
   *The backend will start running at `http://localhost:8000`.*
   *Interactive API documentation (Swagger) is available at `http://localhost:8000/docs`.*

---

### 3. Start the Frontend Application (Next.js)

1. Open a new terminal window and navigate to the `client` folder:
   ```bash
   cd client
   ```

2. Install Node.js dependencies:
   ```bash
   npm install
   ```

3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
   *The frontend will start running at `http://localhost:3000`.*

## 🔑 Authentication Flow & Features

- **Role Selection**: Log in or register as a **Student**, **Faculty**, or **Staff/Admin**.
- **Interactive Login**: Auto-fill preset demo credentials for rapid testing.
- **Registration**: Includes real-time password strength meter, `.edu` email validation notice, and department selector.
- **MongoDB Persistence**: User credentials and profile documents are saved directly into the MongoDB `users` collection.
- **Secure Token Storage**: JWT tokens generated by FastAPI are stored safely in HTTP-only browser cookies (`admin_token`).
